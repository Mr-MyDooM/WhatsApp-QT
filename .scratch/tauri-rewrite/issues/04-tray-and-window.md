# 04: Tray and window

**What to build:** the app has a tray icon to show, hide and quit the app. Close-to-tray and start-minimized work as settings. The window size and position come back after a restart.

**Blocked by:** 01, 03

**Status:** resolved

- [ ] Tray icon with Show/Hide and Quit; clicking the tray icon toggles the window.
- [ ] Close-to-tray setting: on hides the window when it is closed, off quits the app.
- [ ] Start-minimized setting: on starts with the window hidden in the tray.
- [ ] Window size and position are restored after a restart (window-state plugin).
- [ ] Cmd+Q quits.
- [ ] Manual macOS check: each behaviour above, including a restart.
